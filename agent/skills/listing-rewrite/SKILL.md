# Listing rewrite

1. **Description**: one line saying what the agent does and for whom; 60-120 chars.
2. **README**: Markdown with exactly these 6 `##` sections, in order: Summary, Key features, Usage, Use cases, Limitations, Metadata.
   - Summary: 2-3 sentences on what it does and for whom.
   - Key features: 3-5 bullets.
   - Usage: how to use, with one indented example exchange.
   - Use cases: who benefits and when.
   - Limitations: honest limits (input formats, scope, approximations).
   - Metadata: version, category, source of data if any.
   - Cover every capability in the owner's note; drop nothing.
3. **Keywords**: 4-6 short phrases users would type; each must appear word-for-word in the README or description. Prefer plain terms ("flight status", "tide table") over invented compounds.
4. **Starter prompts**: 2-4 concrete questions a first-time user could send, matching the README's examples.
